# sql-data-warehouse-project
Building a modren datawarehouse with sql server, including ETL processes,data modeling.

#### Specification
- **Data Sources**: Import data from 2 source systems (ERP and CRM) provided as source files.
- **Data Quality**: Cleanse and Resolve data quality issue prior to analysis.
- **Integration**: Combine both sources into single, user-friendly data model desgined for analytical queries.
- **Scope**: Focuses on latest datasets only; historization of data is not required.
